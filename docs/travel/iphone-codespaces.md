# Travel Factory from an iPhone

This adds a source-attested travel dashboard alongside the full MoneyPrinterTurbo
studio. It is an implementation for review, not a claim that a real
Singapore/Moscow video or a new GitHub Codespace was successfully produced.
See [audit](audit.md) and [validation](validation.md) for the tested boundaries.

## Launch using Safari

1. Sign in to GitHub in Safari. Open the repository and select the branch/PR
   containing this change. After merge, use `main` normally.
2. Open **Code → Codespaces → Create codespace**. If the mobile menu is cramped,
   Safari's page menu → **Request Desktop Website** makes the editor/Ports panel
   easier to access. Choose the provided **MoneyPrinterTurbo iPhone Studio**
   devcontainer. No local computer or Docker installation is needed.
3. Review your GitHub Codespaces budget and included allowance before creating
   compute. Start with the smallest available machine; full-HD rendering may
   benefit from 4 cores / 8 GB. Set an idle timeout and stop the Codespace when done.
4. Wait for dependency installation. Lifecycle commands install the frozen
   environment and start Streamlit. Startup enforces **Private** visibility for
   port **8501** using GitHub CLI. If that check fails, startup stops; do not make
   the port public to work around it. Check your GitHub/Codespaces permissions
   and the startup output, then rerun the command below after resolving access.
5. Open the editor's **Ports** panel, confirm **8501 → Private**, and tap its
   **Open in Browser** action. GitHub supplies the authenticated HTTPS URL.
   Stay signed in to the owning GitHub account. The container serves HTTP only
   behind this HTTPS gateway. Do not share a public tunnel or remove XSRF/CORS protection.
6. Tap **Travel Factory: sourced comparisons and iPhone workflow**, or select
   Travel Factory in Streamlit's sidebar. The travel form is a single column.

The repository configuration cannot stop a repository owner from manually
changing a forwarded port to public. Keep it Private; Streamlit itself has no
additional login gate. The API port 8080 is deliberately not forwarded or started.
Do not expose another API/UI port without equivalent authentication.

## Recovery after stop, disconnect or restart

Reopen the existing Codespace at GitHub's Codespaces page. Do not create a new
one for every session. `postStartCommand` restarts the UI and checks readiness.
If it does not appear, open the browser editor's Terminal and run:

```bash
bash .devcontainer/install.sh   # only if dependencies are missing / refreshed
bash .devcontainer/start.sh
```

Both commands run from the repository root (they also locate the root themselves).
The start command is idempotent for its healthy running process. Read
`storage/codespaces/webui.log` for startup errors; never share logs before checking
for sensitive content. A stopped/deleted process does not resume its in-flight
render. Completed MP4s and research drafts remain under the workspace's ignored
`storage/`; configuration is in ignored `config.toml`. These survive stop/start
of the same Codespace, but not its deletion. Back up MP4, research and settings
securely. Dependency rebuilds reuse `uv.lock`; never commit secret configuration.

## Make the Singapore vs Moscow pilot

1. Country **Russia**, city **Moscow**, currency **RUB**, budget **S$50** are the
   blank pilot defaults. Start a new research draft if needed.
2. Open public sources in another Safari tab. Prefer the actual Singapore retail
   money changer's dated quote for **selling SGD and receiving RUB**, if one can
   be reliably obtained. Check outlet, direction, fees, minimum exchange amount,
   availability and whether the rate applies to just S$50. An aggregator entry
   is not automatically an executable offer. If there is no qualifying quote,
   leave it missing and stop the factual pilot for review. There is no ECB fallback.
3. Enter one to three genuinely comparable everyday items. Record the same unit
   and size, applicable taxes, retailer and location, dated price and source URL
   in each city. A government average is not a particular shop's observed price.
   Use official sources for any statistical claim. Mark estimates honestly;
   estimates are blocked until replaced by reviewed observations.
4. Enter the source publisher, observation date, access date and a short quoted
   evidence excerpt for every price and the exchange quote. Check each source's
   review box only after reviewing it yourself. Sources older than seven days
   for FX or thirty days for prices require updated observations. These are
   conservative freshness limits, not guarantees of accuracy.
5. Tap **Save research and check missing evidence**. The form can also import a
   research JSON from Files, and exports its template/current draft. No prices
   or exchange rates are generated by an LLM or silently filled in.
6. Review the calculated quantities and storyline. Each item independently gets
   the whole budget: this is **not a combined shopping basket**. The destination
   budget is `(SGD budget − SGD exchange fee) × local currency per SGD`, rounded
   down only when calculating whole purchasable units. The Singapore budget
   remains SGD50. Note fees and minimum-order constraints in the source record.
7. Choose an English Edge voice and speed. Comparison graphics are built in.
   Optionally upload your own licensed JPEG/PNG background from Photos or Files;
   export HEIC as JPEG first. It is marked illustrative. You can instead record
   the exact reviewed script on your phone and upload a 35–45 second MP3/WAV
   plus its matching SRT. Caption text must match the script. A person still
   needs to check that uploaded speech actually matches those captions.
8. Confirm the storyline review and tap **Generate captioned vertical video**.
   Rendering uses the existing engine, with 1080×1920 portrait output, subtitles,
   comparison graphics and no paid image/video/music calls. Actual narration
   must measure 35–45 seconds; adjust voice speed or item count and retry when
   prompted. This is a duration gate, not a promise that every script fits.
9. Preview the MP4 and listen to it. Tap **Download MP4 to iPhone**, then use
   Safari's Downloads menu or **Share → Save to Files**. Also download the source
   JSON: it contains the dated research, assumptions, calculations, narration
   and research digest. Transfer both if reviewing elsewhere.
10. Record approval or reject publication. Approval refers to the exact video,
    research and platform set. Nothing uploads merely because you approve.

Research is user-attested, not automatically independently verified. The blank
pilot remains blocked until real source data is available. The test render uses
synthetic test fixtures and a tone; it is not the requested real pilot.

## Existing AI, stock, uploads and music

The full studio remains available from the travel page. Its existing mobile
uploads support footage, images and scripts/presets; Safari provides Files and
Photos pickers. Use its normal preview/download controls for general videos.
The travel page intentionally uses factual comparison graphics instead of stock
search; automatic integration of sourced story scenes with stock footage is a
future improvement. Do not describe stock footage as the listed shop/product.

- **Scripting:** the travel page uses a deterministic, sourced storyline at no
  LLM cost. Existing **OpenAI – Codex** uses device-code login where the account
  supports it. Open the offered verification page in Safari; entitlement is
  account-dependent. The separate native ChatGPT OAuth flow needs a same-machine
  loopback callback and is not supported from iPhone→Codespaces. A ChatGPT
  subscription does not provide OpenAI API credits. API scripting requires an
  explicitly selected provider and its separate credentials/billing.
- **Alternative LLM:** Ollama is already supported but is not installed or pulled
  automatically: small Codespaces machines may lack RAM and downloads/storage
  cost time and quota. Free-tier API limits and availability change; configure
  one explicitly in the full studio, with no automatic paid fallback.
- **Stock:** existing Pexels / Pixabay integrations require their respective free
  developer keys and compliance with provider rate limits and asset terms.
  Configure the existing password fields in the full studio. No key is needed
  for default travel comparison graphics or your own media.
- **Voice/subtitles:** Edge TTS uses an external Microsoft service without an API
  key, with no promised SLA or permanent free access. Existing boundary-based
  subtitles avoid downloading a Whisper model. Narration upload is the offline
  alternative, with a matching SRT prepared and reviewed separately.
- **Music:** travel exports default to no music. The full studio supports music;
  choose music you have a license to use commercially, and retain attribution
  where required. No bundled track is automatically asserted royalty-free.

## Credentials and publication

Use **GitHub account Settings → Codespaces → Secrets** to add repository-scoped
secrets. Restart the Codespace after changing them. The travel publishing form
reads `UPLOAD_POST_API_KEY` and `UPLOAD_POST_USERNAME` if present; otherwise enter
credentials in its masked form. Those widget values live in the browser session
and are not written to the travel research or publication records. Other existing
provider settings may persist in ignored `config.toml`; lifecycle scripts use a
private umask. Do not commit this file, `.env`, OAuth stores or secret exports.
Do not display keys in screenshots or paste them into scripts.

No social account is registered by these changes. To enable the optional
Upload-Post action, create your own account, check its current pricing/plan,
connect your Instagram/TikTok/YouTube accounts with the required account types and
permissions, then configure its API key and connected user. A paid plan or
platform approval may be required; none is activated automatically.

**Automatic publishing is disabled by the Codespaces startup profile** even if an
old general-studio setting enabled it. Travel rendering never calls auto-upload.
After preview, choose platforms, record approval, then separately check the
explicit publication confirmation and tap **Publish approved video now**.
YouTube starts **private**, with an explicit made-for-children declaration.
Instagram/TikTok visibility follows the provider/account settings; inspect them
before sending. A changed MP4, source record or platform selection invalidates
approval. A rejected video cannot upload. An uncertain response is persisted and
blocked from blind resubmission: reconcile its request in Upload-Post first.
Approval receipts are local single-owner workflow records, not a multi-user
compliance or identity-signature system. Avoid giving other people your private
Codespace session.

## Costs and limits

No paid calls are made by default. Local graphics, subtitles and rendering incur
Codespaces compute/storage use. Your GitHub allowance, machine size, usage and
retention determine actual charges; check GitHub Billing before starting and set
limits. There is no fixed per-video cost guaranteed by this repository.
Stock free developer accounts have quotas and license conditions. Edge access is
best-effort. Codex/ChatGPT allowances depend on account entitlements. API LLMs,
AI footage, generated music and Upload-Post can bill separately; they are not
needed for the default graphics workflow and require explicit configuration.
